# Distribuição

Versão experimental para instalação manual no computador. Esta adaptação não foi publicada na Chrome Web Store, na loja do Edge, nem no Firefox Add-ons. O código-fonte e o ZIP para instalação manual ficam no [GitHub](https://github.com/heluiz/elo-instagram).

A pasta de produção é `.output/chrome-mv3`. O ZIP de cada Release é gerado a partir dela com `npm run zip`.

Não reutilize o identificador de loja do IgDiff para publicar esta adaptação. Preserve a licença e os créditos. Antes de qualquer publicação, conclua a validação descrita em docs/VALIDACAO.md.
