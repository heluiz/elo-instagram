# Distribuição

Versão experimental para instalação manual no computador. Esta adaptação não foi publicada na Chrome Web Store, na loja do Edge, no Firefox Add-ons ou no GitHub do usuário.

A pasta de produção é `.output/chrome-mv3`. O pacote entregue copia seu conteúdo para `extensao`.

Não reutilize o identificador de loja do IgDiff para publicar esta adaptação. Preserve a licença e os créditos. Antes de qualquer publicação, conclua a validação descrita em docs/VALIDACAO.md.
